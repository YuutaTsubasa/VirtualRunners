# 虛擬跑跑樂 UI Concept — 晴空跑道

日期：2026-10-24。供視覺評估的設計提案，未實作。使用者已選擇「晴空跑道：明亮、輕快、有速度感」。

## 設計定位與依據

90 年代賽璐璐角色在明亮、連續向前的跑道上穿越六個世界。介面以跑道節點、跳躍弧線、里程牌與終點標記形成識別，保留系列角色和服裝。
目前 app.css、TitleScreen、Logo、SelectScreen 及原 ui-concept-v1/DESIGN.md 延用闖天下的墨黑、暖白、朱紅、漫畫分格與隊伍構圖；排球 Logo 則是金屬金字、深藍厚框與環繞速度帶。此次從字形、形狀、構圖、資訊優先順序一起重新設計。

比較方向：街頭疾走的塗鴉與螢光很有個性，但對水下、冰山、森林的適應性較低；奇幻旅程的旅票、手帳有探索感，但較靜態。採晴空跑道，路線圖只作導航語言，不增加旅行收集系統。

圓角路牌、圓形路線節點、膠囊型數字標記；以 1920×1080 為基準，面板圓角約 20px、輪廓 2–3px、柔和短陰影 4–6px。數值和文案使用清楚的繁體中文黑體，標題較厚，Logo 才做客製字形。正文不傾斜。透明玻璃、厚金邊、刷墨框、整頁斜切框、球體/球網/隊徽不納入這套語彙。
焦點以深湖藍外環＋小箭頭＋選取文字同時表達；鎖定狀態有鎖圖示與文字，不能只降低透明度。亮橘按鈕用深墨字，白字不可直接鋪在淺天藍上。

## Logo

完整繁中「虛擬跑跑樂」，英文「VIRTUAL RUNNERS」。虛擬較小但清晰；跑跑樂為圓厚、略有彈性、接近直立的標題字，兩個跑略微錯落形成踏步節奏，閱讀順序仍是完整水平字串。橘色與晴空藍色塊、雲白留白、深湖藍細外框；採平面賽璐璐色層。小型跳躍弧線可連接兩個跑，但不穿過字內空間，不形成包圍字標的運動軌道。
小尺寸需另做簡化字標或雙路線節點圖示。Concept 裡的字標是提案，正式上線前重建可縮放、可校對的版本。

## 六張 Concept 的配置

1. 品牌元件板：Logo、六個主要色塊、按鈕一般/選取/鎖定狀態、里程牌、三顆心、金幣與關卡節點。建立共同形狀語言。
2. 首頁 16:9：整幅晴空與白色都市高架步道，主角朝右奔跑。Logo 位於左上開闊天空，人物集中右側中景；底部約 26% 是水平導航碼頭。單機遊玩是最大橘色起跑牌，開設房間、加入房間為兩個藍白牌，操作說明與設定為較小工具按鈕。保留原有五項功能。以水平動線和留白建立速度感，不用左右各一名對戰者的構圖。
3. 選角 16:9：左中為小翠的大幅奔跑姿態，右側白色能力牌寫小翠、幸運磁鐵、附近的金幣會自己飛過來。底部兩列名冊，10 位一般角色＋阿翼鎖定格；阿翼未解鎖不露出身份。關卡模式下主按鈕「選擇關卡」，無盡模式用「開始跑」。不發明速度/力量星等，不展示四人同隊席位。
4. 地圖 16:9：上方六世界導覽，主區為白色都市的橫向彎曲高架步道路線，八個節點標 1-1～1-8，最後為魔王。示例選中 1-3 天台夜路，右下詳細牌顯示已取得星數並有「開始跑」。已完成、當前、上鎖各有圖形提示。地圖可俯視，實際遊戲仍為橫向跑酷。名稱沿用現有資料。
5. 遊戲 HUD 16:9：保留側面橫向跑酷、角色靠左約 25%、前方至少一半畫面可判讀。左上小翠頭像＋三顆心；中央 1-1 白色大道＋到終點的路線進度；右上金幣 42/80、分數 0042600、暫停。示例正常單機，不顯示名次、魔王血條、無盡速度。下方角落只放小型鍵位提示，觸控版才顯示可點操作鈕。障礙、金幣、平台使用既有造型。
6. 過關 16:9：終點天空、勝利跑姿、浮動里程牌。顯示 1-1 白色大道、過關、星星 3/3、分數 0042600、金幣 68/80。三顆星條件：過關、金幣達 70%、沒受傷。主行動「下一關」，次行動「再跑一次」「關卡地圖」。示例數字非玩家真實紀錄，不增加獎品貨幣或每日任務。

## 其他狀態沿用

無盡 HUD 將中央進度替換為距離和速度倍率；魔王關中央替換為既有魔王名稱/HP。連線最多 8 人：右側窄排名條，以名次＋名稱＋自身標記辨識，其他玩家仍在遠景層；不加入左右隊伍/VS 或球賽比分。八列排名可收起成自身及鄰近名次，完整清單暫停面板可查。
暫停與設定使用白色圓角牌與淡藍遮罩；連線必須保留「連線遊戲不會暫停」提示。開房與加入使用相同路牌元件，保持原有房號/名字/連線流程。

## 動效、易讀性與實作交接

選中節點短距離向前移動 6–10px；換頁如路線向右展開；確認時小幅彈起；大背景只做很慢的雲層移動。提供減少動態效果，HUD 和數值不持續跳動。動畫避開角色前方的障礙判讀區。
以 16:9 舞台與既有 cqw/cqh 適配；1920 稿中正文建議 26–32px、主要按鈕 34–40px。支援鍵盤/手把可見焦點，觸控有效區至少 48 CSS px。英文/日文較長文字預留約 30% 彈性。
Concept 展示方向與層級，精確字形、肖像、對比度、碰撞資訊及控制提示應在實作時以正式字型與既有元件重建。此次不更動遊戲程式，不交入會自動接入的 art-inbox。保存於 art-work/runner-ui-concept-v1，包含設計稿、圖片與生成提示；使用內建 image_gen。
