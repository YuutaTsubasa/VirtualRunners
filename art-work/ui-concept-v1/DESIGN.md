# 虛擬闖天下 UI Concept v1

日期：2026-10-24。狀態：供使用者評估的視覺提案，不是已實作介面。

## 設計定位

推薦方向：**90 年代熱血冒險動畫 × 四人街機闖關**。

讓玩家第一眼讀到「麻將館的夥伴一起出發、穿過六個世界」，以漫畫分格、章節牌、隊員編號及動畫標題字形成自己的識別。人物保持原有 90 年代賽璐璐畫風、服裝與個性；遊戲中維持 Q 版比例。

比較過的方向：街頭塗鴉很有打擊感，但不足以涵蓋海底、冰山與城堡；冒險手帳能表達旅程，但較容易讓人聯想到文字 RPG。採用動畫冒險主題，少量吸收街機的粗輪廓與路線圖的章節感。

現有 UI 的運動感來自深藍／金黃主色、金屬漸層斜體 Logo、流線、雙斜切按鈕和居中的大選單。新版從構圖、輪廓、文字與互動提示一起調整。

## 色彩與形狀

| 用途 | 色碼 | 規則 |
| --- | --- | --- |
| 墨黑 | `#202329` | 文字、輪廓、HUD 底與硬陰影 |
| 暖白 | `#F5EFDF` | 選單留白、文字反白、人物卡底 |
| 朱紅 | `#D94B3D` | Logo 闖字、選中項、主要行動 |
| 青綠 | `#287F78` | 導覽、章節、次要互動 |
| 杏黃 | `#E9B85E` | 少量提示及獎勵，避免大面積金色 |

直角矩形為基本元件，2–4 px 墨線與短距離實色陰影（以 1920×1080 設計稿計）。不規則輪廓只用於大標題與事件章。紙感和網點只放在背景、插畫邊角，文字及數值下保持平整。各世界能換背景與章節色，但共同元件保持一致。

角色自己的藍衣、金髮等原有配色不受 UI 色盤限制。

## Logo

主標完整文字「虛擬闖天下」，英文「VIRTUAL QUEST」。

設計粗實、近直立、帶手寫頓點的中文標題字，整體不做運動隊徽般的大幅斜切。以暖白字、墨黑外框和短硬陰影構成主體；中央「闖」用朱紅突出，保留可辨識的字形。闖字的門框筆勢可以暗示入口與冒險，不能拆成難讀的圖案。英文縮小置於獨立黑色標籤。

避免球體、環繞軌道、翅膀、運動速度帶、盾徽及金屬漸層。首頁呈現 Logo 初稿；後續已衍生獨立透明圖 logo-transparent.png，專用小尺寸版尚未製作。

## 首頁 Concept

16:9。左側約 40% 是清晰的暖白操作區，右側約 60% 是人物與六世界冒險插畫。Logo 位於左上，主選單靠左向下，讓畫面不再是 Logo 和按鈕堆在中央、兩側各放一名球員。

選單沿用實際功能：「單機遊玩」「開設房間」「加入房間」「操作說明」「設定」。目前選項用朱紅實底＋暖白字＋小三角游標；未選項以墨黑字和細分隔線呈現。控制提示保留文字及按鍵，不能只靠顏色。

右側是小春、小翠、阿明共同前進的動畫主視覺；都市作近景，森林、雪峰與城堡作遠景，海底與熔岩以小幅漫畫窗補充。原角色服裝保持一致。插畫的衝擊線限制在人物後方。

## 選角 Concept

標題「集結夥伴」，小標「選擇角色」。採 3 個閱讀區：左側角色名冊、中間當前角色大立繪、右側能力與闖關設定；底部是四個同隊席位與出發按鈕。

左側顯示 10 名一般角色，以及隱藏角色的鎖定／問號狀態。名冊格子直接使用既有肖像。選中格有朱紅邊框、小游標及 1P 文字；已被其他玩家選取的狀態以席位編號標籤辨識。

中央以小春作示範，顯示「小春」及原角色介紹。右側能力只使用已有的速度、力量、體力，示範值分別 5、3、2，以五格條呈現，數值與原資料一致。

設定沿用玩家人數、CPU 夥伴、難度、起始世界、生命數。主層只強調常用項，較長設定可歸入一個完整設定面板；這是層級建議，不能刪除現有功能。

四個席位是同一支隊伍，沒有 VS、兩隊陣營或對戰時間。每席保留編號、名字、控制來源、確認狀態；多人選角順序與可重複規則沿用程式。Concept 展示預備隊伍，不代表新增即時加入或額外玩法。

## 戰鬥 HUD Concept

以 1920×1080 畫面為基準。頂端 4 個等寬隊員牌：每牌含肖像、1P–4P／CPU、名稱、HP、剩餘生命與七位數分數。單牌高度約 112 px，四牌橫排，頂端安全邊界 24 px；長名字截斷而不擠壓 HP。

HUD 用墨黑平底、暖白字、青綠血條，席位以色條＋編號雙重標記。低血量用朱紅及短暫閃爍輔助，但不以閃爍作唯一提示。分數字級低於姓名與 HP。彩色只佔少量邊框，不讓四張面板遮住關卡。

本張 Concept 展示「白色都市／1-1 白色大道」一般戰鬥，使用小春與既有都市敵人。四位隊員可用 1P＋3 CPU 示範，頂部資訊與場內角色對應。下方不常駐大型操作列，保留地面縱深。清場時在右側出現小型「GO →」章；一般戰鬥不顯示 Boss 血條。Boss 戰另用底部窄條顯示名字與 HP，並給地面讓出安全區。

不新增未存在的連段計數、怒氣、裝備、魔法、任務追蹤或 RPG 技能列。

## 其他頁面延伸

- 暫停／設定：墨黑半透明遮罩＋暖白矩形面板，朱紅焦點，文字排版整齊。連線選單要保留「連線遊戲不會暫停」提示。
- 過關：使用朱紅「突破！」章及角色表情，顯示實際結算資料；避免球賽比分板。
- 關卡章節：短暫的世界名＋章節數標籤，必要時附簡化路線圖；不遮擋戰鬥。
- 動效：游標短推進、漫畫格切換、選角確認蓋章。避免整個介面持續浮動。提供減少動態效果的實作建議。
