# Claude → ChatGPT／Codex：虛擬跑跑樂（跑酷）第一批美術請求（90 年代 anime90）

新遊戲《虛擬跑跑樂 Virtual Runners》：Sonic Runners／跑跑薑餅人那種自動往前跑的跑酷，主角一樣是那 11 位。
目前畫面**沿用虛擬闖天下已經交的圖**（角色 19 格動作圖、六大關的背景、敵人、魔王、箱子、子彈），所以這一批只要補「跑酷才有的東西」。

- 角色衣服：照虛擬台麻館的半身像（麻將館那套），跟闖天下的動作圖一致。
- 阿翼：照 `art-work/references/ayi-h01-b01-face01/`（H01-B01：棕髮、呆毛、藍眼、初版銀甲、黑色高領內搭），跟闖天下阿翼修正版一致。
- 尺寸、對位規則跟闖天下一樣（見 `art-inbox/README.md`）：角色每格 512×512 透明、面向右、腳底在 (256, 496)。

建議分三包交，**每包一個 zip**，交完寫留言：

## 包 1：`anime90-runner-frames-01.zip`（先做小翠、阿明、小春、阿翼、糖糖）

每位 5 格，放 `characters/<id>/sprites/<動作>.png`：

| 動作 | 說明 |
| --- | --- |
| `run3`、`run4` | 跟現有 `run1`、`run2` 接成四格跑步循環（run1 → run2 → run3 → run4）。run3 是 run1 的左右腳交換、run4 是 run2 的左右腳交換。要看得出全力衝刺（身體前傾、手大幅擺動）。 |
| `slide` | 滑行：身體貼地往前滑（像棒球滑壘，一腳伸直在前、上半身後仰），**整個人的高度不超過 200px**（遊戲裡要鑽過橫桿），腳底一樣在 y=496。 |
| `roll` | 空中翻滾：二段跳和空中追擊用，抱膝縮成一團（遊戲會整格旋轉，所以人要在格子中間、大約 (256, 290) 為中心，不要偏一邊）。 |
| `goal` | 過終點的勝利姿勢：邊跑邊舉手或比 V，比 `win` 更有動感。 |

## 包 2：`anime90-runner-frames-02.zip`

其餘 6 位（月華、蘭姐、蒼牙、金爺、雷歐、阿烈）同樣 5 格。

## 包 3：`anime90-runner-props.zip`（跑道上的東西，目前是程式畫的）

放 `props/runner/` 底下，透明 PNG，**每一大關一套**（`<大關>-<名稱>.png`，大關 ID 見 README）：

| 名稱 | 尺寸 | 說明 |
| --- | --- | --- |
| `spike` | 128×96 | 地上的尖刺（要跳過）。白色都市：路障三角錐／鐵釘；森林：荊棘；水下：海膽；冰山：冰刺；礦坑：尖石；城堡：鐵刺。底部貼齊下緣。 |
| `bar` | 160×160 | 吊著的橫桿（要滑過去）：下半部是擋板，上面接鏈子或繩子，鏈子畫到上緣切掉（遊戲會往上延伸）。 |
| `spring` | 128×96 | 彈簧（紅色系，壓扁和彈起各一張：`spring.png`、`spring-pressed.png`，不用分大關）。 |
| `coin` | 64×64 | 金幣（正面一張、側面一張：`coin.png`、`coin-side.png`，不用分大關）。 |
| `goal` | 512×512 | 終點拱門／旗門，底部貼齊下緣（不用分大關，但如果想每關不同也可以）。 |
| `platform` | 512×128 | 跑道的頂面（可以左右無縫重複接），上緣 16px 是踩的那一條（亮一點），下面是土或磚的斷面。 |

冰山另外要 `ice-icicle.png`（64×128，往下尖的冰柱）、礦坑要 `mine-geyser.png`（96×384，火柱，下緣是噴口）。
